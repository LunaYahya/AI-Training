## Day4 -Pandas: Tabular Data
## Objectives
- Load a real dataset into a DataFrame and inspect its structure.
- Select columns and filter rows by condition.
- Clean missing values and duplicates, and aggregate data with groupby.
## Topics Covered
-Series vs. DataFrame
- Loading and inspecting data: read_csv, head, info, describe
- Selecting and filtering: columns, boolean filtering, .loc/.iloc
- Cleaning: missing values, duplicates, type conversion
- Grouping and aggregation: groupby, agg (split-apply-combine)
## Tasks
Task1 :Load a provided CSV dataset into a DataFrame and report its shape, columns, and dtypes.
Task 2: Count missing values per column and handle them (fill or drop) with a documented justification.
Task 3: Filter the data to a meaningful subset (e.g. rows above a threshold) and describe what you find.
Task 4: Use groupby to compute an aggregate statistic per category and interpret the result in a
Markdown cell.
