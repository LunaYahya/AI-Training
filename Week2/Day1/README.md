## Day 1 — Descriptive Statistics
## Overview
this day we  study the fundamental concepts behind descriptive statistics,Descriptive statistics can be used to understand the properties of the data without making any predictions, 
we  use various statistical measurements to describe the dataset.
## Learning Objectives
In this lab, we will use various statistical measurements to describe the dataset.
Calculate the mean, median, and mode and decide which metric would be more suitable for a given dataset.
Calculate and interpret variance, standard deviation, and IQR.
Discuss how an outlier impacts each center or spread statistic individually.
## Key Concepts
Why Descriptive Statistics Comes Before Modeling: Learning about the need to summarize data based on the center, spread, and shape of data for exploratory data analysis  and model evaluation purposes.
Measures of Central Tendency: Deciding whether mean, median, or mode is applicable to the case.
Measures of Spread & Dispersion: Examining range, variance, standard deviation, and interquartile range (IQR).
Measures of Percentiles & Quartiles: Dividing the data into four equal parts.
