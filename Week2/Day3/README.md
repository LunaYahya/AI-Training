In the third day, we learned about the basic knowledge of linear algebra, which is described as the backbone of machine learning mathematics. Linear algebra is used to model and represent datasets, model parameters, and all the operations performed by machine learning algorithms to make predictions.

## Learning Objectives

On this day, we learned to represent data samples as vectors and datasets as matrices using the NumPy library. We computed the dot product of vectors, which is the most basic concept of making predictions in linear model and also performed matrix multiplication considering their shapes.

## Key Concepts

## Why Linear Algebra is Important for Machine Learning?
ML datasets are represented using matrices while the parameters of a model are represented using vectors/matrices. Most of the computations in machine learning use linear algebra.
- Vector: It represents a single data sample and its features.
- Matrix: It represents the whole dataset where rows represent the samples and columns represent the features.
- Dot Product: This is the basic computation used by most of the machine learning algorithms to compute the predictions.
- Matrix Multiplication: Makes possible the efficient prediction for multiple data samples at once but requires the same dimensionality of matrixes.
