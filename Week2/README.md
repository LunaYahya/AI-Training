#  Week 2 – Mathematics & Exploratory Data Analysis (EDA)
## Overview
In the second week, we studied the mathematics necessary for Machine Learning and explored those concepts using Exploratory Data Analysis (EDA). The topics that were discussed included descriptive statistics, probability, linear algebra, and methods of exploring data.
## Topics to be covered
## Day 1 – Descriptive Statistics
- Central Tendency (Mean, Median, Mode)
- Spread (Range, Variance, Standard Deviation, IQR)
- Percentile and Quartiles
- Selection of appropriate Statistical Measures depending on the data
## Day 2 – Probability & Distributions
- Probability Rules (Complement Rule, Addition Rule, Multiplication Rule)
- Conditional Probability
- Baye’s Theorem
- Commonly Used Probability Distributions (Normal, Binomial, Uniform)
## Day 3 – Linear Algebra for Machine Learning
- Vectors & Matrices
- Dot product
- Matrix Multiplication
- Mathematical representation of Datasets for Machine Learning Models
## Day 4 – EDA Part 1: Distributions & Outliers
- Importance of Exploratory Data Analysis
- Univariate analysis
- Histograms, Box plots, Count Plots and Kernel Density Estimation (KDE) plots
- Identification of Outliers using IQR
## Day 5 – EDA Part 2: Correlation & Data Storytelling
- Bivariate Analysis
- Scatter Plots and Grouped box plots
- Correlation Matrix and Heatmaps
- Pair Plots
- Data Storytelling
- Creating a complete EDA notebook
## Tools used
- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook
- Git & GitHub
## Learning Outcomes
At the end of this week, I acquired good knowledge of mathematical ideas for Machine Learning and was able to conduct full Exploratory Data Analysis (EDA). I am now able to summarize data sets through descriptive statistics, use concepts of probability, work with vectors and matrices, examine distribution of features, find outliers, look at relationships among features, understand correlation, and present findings through visualizations and data storytelling.
