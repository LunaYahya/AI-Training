# Week 3 — Supervised Learning
## Overview
In week 3, I acquired knowledge about the basics of supervised machine learning such as regression and classification along with building and evaluating various machine learning models using Scikit-learn.
## Topics Covered
- Day 1: Supervised Learning Concepts & Scikit-learn API
- Day 2: Linear Regression and Regression Metrics
- Day 3: Logistic Regression and Classification Metrics
- Day 4: Decision Trees, Random Forests, SVM, and k-NN
- Day 5: End-to-End Supervised-Learning Mini-Project
## key Skills
- Generating datasets with features (X) and targets (y).
- Splitting the data into train and test datasets.
- Training and assessing various regression and classification models.
- Interpreting various metrics used for performance evaluation.
- Comparing various machine learning models appropriately.
- Preprocessing without any data leakage.
- Selecting and justifying the right model and metric.
## Practical Experience
Throughout the week, I gained hands-on experience in building different supervised learning models, assessing their performance using the right metrics, comparing models using the same dataset, and conducting a complete mini-project on EDA and preprocessing to modeling and assessment.
## Learning Outcomes
At the end of Week 3, I had gained knowledge about how to preprocess data by segregating the feature variable (X) from the target variable (y), split into train and test sets, and training various supervised learning models. The performance evaluation of regression and classification models through the metrics like MAE, RMSE, and R² for regression and precision, recall, F1 score, and AUC-ROC for classification.
