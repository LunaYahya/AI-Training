# Week 5 – Unsupervised Learning 
## Introduction
This week was dedicated to studying unsupervised learning, dimensionality reduction, and anomaly detection and working on Phase 3 capstone project planning.
## Days Summary
### Day 1 – K-Means Clustering
- Differentiated between supervised and unsupervised learning.
- Applied K-Means clustering.
- Used StandardScaler for scaling features.
- Calculated the number of clusters based on Elbow Method and Silhouette Score.
- Interpreted clusters and centroids.
### Day 2 – DBSCAN and Hierarchical Clustering
- Studied the shortcomings of K-Means.
- Applied DBSCAN algorithm for density-based clustering and noise detection.
- Worked with hierarchical clustering and dendrograms.
- Compared K-Means, DBSCAN, and hierarchical clustering.
### Day 3 – PCA
- Learned about curse of dimensionality.
- Applied Principal Component Analysis (PCA).
- Calculated explained and cumulative explained variance.
- Reduced high-dimensional dataset while retaining the majority of variance.
- Visualized the reduced dataset in 2D space.
### Day 4 – t-SNE and Anomaly Detection
- Applied t-SNE algorithm for high-dimensional data visualization.
- Compared PCA and t-SNE algorithms.
- Studied unsupervised anomaly detection methods.
- Applied Isolation Forest algorithm.
- Analyzed found anomalies and contamination parameter.
### Day 5 — Phase 3 Project Selection & Sprint 1 Planning
- Entered the Phase 3 capstone project.
- Selected the **Cardiac Patient Monitoring System**.
- Defined the problem statement and Definition of Done.
- Created the Sprint 1 backlog and effort estimates.
- Defined acceptance criteria and the Sprint 1 goal.
- Planned the GitHub feature-branch and Pull Request workflow.
