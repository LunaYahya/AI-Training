# Day 2 — Activations, Forward Propagation & Loss

## Learning Objectives

- Understand the importance of activation functions in Neural Networks.
- Know why there is a need for non-linear activation functions.
- Familiarize yourself with ReLU, Sigmoid, Tanh, and Softmax activation functions.
- Be aware of how different activation functions manipulate input data.
- Know how to choose the right output activation function.
- Know some popular loss functions and their uses.
- Be familiar with Forward Propagation.
- Run a forward propagation on a tiny Neural Network using NumPy.
- Determine the final prediction and Binary Cross Entropy loss.
## Key Topics 

- Activation Functions
- ReLU, Sigmoid, Tanh, and Softmax
- Loss Functions
- Binary Cross-Entropy
- Forward Propagation
- Weighted Sum and Bias
- Neural Network Prediction

## Hands-On Lab (Tasks)

- Step 1: Plot ReLU, sigmoid, and tanh over a range of inputs to see how each transforms values.
- Step 2: For the Phase 3 project task, decide the correct output activation and loss function, and justify both.
- Step 3: By hand or in NumPy, compute one forward pass for a tiny 2-layer network on a sample input.
- Step 4: Document the choices and the forward-pass result in Markdown.

## Tools Used

- NumPy
- Pandas
- Matplotlib
- Jupyter Notebook

## Learning Outcomes
At the end of the day, I was able to understand the purpose of an activation function and select the right activation and loss function for a binary classification task. I was also able to implement a simple forward pass of a neural network using NumPy, predict using Sigmoid, and calculate the Binary Cross-Entropy loss.
