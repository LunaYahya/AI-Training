# Day 4 — Building & Training a Network in Keras
## Learning Objectives
- Build a neural network using the Keras Sequential API.
- Compile, train, and evaluate a model.
- Understand training history and loss/accuracy curves.
- Apply Batch Normalization and Dropout to reduce overfitting.
## Key Topics
- TensorFlow / Keras
- Sequential API
- Dense Layers
- Compile / Fit / Evaluate
- Training History
- Loss and Accuracy Curves
- Batch Normalization
- Dropout
## Hands-On Lab (Tasks)
- Step 1: Build a Keras Sequential network for the Phase 3 project.
- Step 2: Compile with Adam and the appropriate loss, then train for at least 30 epochs with validation data.
- Step 3: Plot training and validation loss and accuracy and diagnose the model fit.
- Step 4: Add Dropout and/or Batch Normalization and compare the results.
- Step 5: Evaluate the final model on the test set and compare it with the Day 1 baseline.
## Tools Used
- TensorFlow / Keras
- NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook / Colab
- Git / GitHub
## Learning Outcomes
At the end of the day, I was able to build, train, and evaluate a neural network using Keras, interpret training and validation curves, and apply Dropout and Batch Normalization to reduce overfitting and improve training stability.
