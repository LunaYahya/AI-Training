# Day 5 — Tuning, Evaluation & Sprint Review
## Learning Objectives
* Tune a neural network systematically by changing one hyperparameter at a time.
* Understand the effect of learning rate, network size, dropout, and batch size.
* Use EarlyStopping and ModelCheckpoint to train efficiently and keep the best model.
* Evaluate the final model using the test set.
* Compare the tuned model with the baseline model.
## Key Topics
* Neural Network Tuning
* Learning Rate
* Network Size
* Dropout
* Batch Size
* EarlyStopping
* ModelCheckpoint
* Model Evaluation
* Baseline vs Tuned Model
* Sprint Review
## Hands-On Lab (Tasks)
- Step 1: Tune the network by changing one hyperparameter at a time and record each run's validation score.
- Step 2: Add EarlyStopping and confirm training halts at the right point, keeping the best weights.
- Step 3: Assemble the Sprint 1 evidence: baseline vs. neural network scores, architecture, and loss curves.
- Step 4: Ensure all Sprint 1 work is committed, the pull request is merged after mentor approval, and the notebook is documented.
- Step 5: Present the Sprint Review, then write the Retrospective with one concrete change for Sprint 2.

## Learning Outcomes
At the end of the day, I was able to systematically tune a neural network, use EarlyStopping and ModelCheckpoint to improve the training process, evaluate the final model on unseen test data, and compare the tuned model with the baseline as part of the Sprint 1 review.
