# Day 1 — Sprint 2 Planning & Building and Transferring a CNN

## Learning Objectives
* Complete Sprint 2 planning and define the core-model backlog.
* Build and train a small CNN from scratch for image classification.
* Understand the effect of data augmentation on model performance.
* Apply transfer learning using a pre-trained MobileNetV2 model.
* Compare different CNN approaches based on accuracy and training time.
 
## Key Topics
* Sprint 2 Planning
* Convolutional Neural Networks (CNNs)
* CNN from Scratch
* Data Augmentation
* Training and Validation Curves
* Transfer Learning
* MobileNetV2
* Model Accuracy
* Training Time
* Model Comparison

## Hands-On Lab (Tasks)
* Step 1: Build and train a small CNN from scratch on the melanoma skin cancer image dataset and record its accuracy.
* Step 2: Add data augmentation and compare the new validation curves with the previous CNN run.
* Step 3: Apply transfer learning using a frozen pre-trained MobileNetV2 model and compare accuracy and training time.
* Step 4: Document which approach performed best and explain why in Markdown.

## Tools Used
* TensorFlow 
* NumPy

## Learning Outcomes
At the end of the day, I was able to build and train a CNN from scratch, apply data augmentation, use transfer learning with a pre-trained MobileNetV2 model, compare the different approaches based on accuracy and training time, and identify the best-performing approach for the melanoma skin cancer classification project.
