# Day 2 — Building CNNs & Transfer Learning

## Learning Objectives

* Build and train a CNN from scratch for image classification.
* Understand how convolutional, pooling, and dense layers work together.
* Apply data augmentation to improve model generalization.
* Use transfer learning with a pre-trained MobileNetV2 model.
* Compare CNN approaches based on validation accuracy and training performance.

## Key Topics

* Convolutional Neural Networks (CNNs)
* Convolutional Layers
* Pooling Layers
* CNN from Scratch
* Data Augmentation
* Validation Performance
* Transfer Learning
* MobileNetV2
* Frozen Pre-trained Layers
* Model Comparison

## Hands-On Lab (Tasks)

* Build and train a CNN from scratch on the melanoma skin cancer image dataset.
* Evaluate the CNN using training and validation accuracy and loss.
* Apply data augmentation and observe its effect on validation performance.
* Use a pre-trained MobileNetV2 model with frozen layers for transfer learning.
* Compare the CNN from scratch, augmented CNN, and transfer learning approaches.
* Document the results and identify the best-performing approach.

## Tools Used
* TensorFlow

## Learning Outcomes
At the end of the day, I was able to build a CNN from scratch, understand the role of convolution and pooling layers, apply data augmentation to improve generalization, use transfer learning with a pre-trained MobileNetV2 model, and compare the different approaches based on their validation performance.
