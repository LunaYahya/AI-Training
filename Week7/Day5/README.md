# Day 5 — Advancing the Core Model & Sprint Review

## Learning Objectives

* Select the appropriate neural network architecture based on the project's data type.
* Improve and tune the project's core model beyond the Sprint 1 baseline.
* Track and compare multiple model experiments.
* Evaluate the final model using appropriate classification metrics.
* Complete the Sprint 2 Review and Retrospective.

## Topics Covered

* Matching architecture to data type.
* Advancing the core Dense Neural Network.
* Hyperparameter tuning and experiment tracking.
* Comparing Week 6 baseline, Sprint 1, and Sprint 2 models.
* Training and validation curves.
* Confusion matrix and classification metrics.
* Sprint Review and Retrospective.

## Hands-On Lab
- Step 1: Confirm and justify the core architecture for the project based on its data type.
- Step 2: Train and tune the improved core model, logging each experiment's config and metric.
- Step 3: Assemble a metric table comparing the Sprint 2 model to the Week 6 baseline and the Sprint 1
network.
- Step 4: Ensure all Sprint 2 work is committed, the pull request is merged after mentor approval, and the
notebook is documented.
- Step 5: Present the Sprint Review, then write the Retrospective with one concrete change for Sprint 3
