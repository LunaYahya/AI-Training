# Week 9 — MODEL DEPLOYMENT — SPRINT 4


## Overview

Week 9 focused on taking the **Melanoma Skin Lesion Classification** project from a trained model to a complete, deployed machine learning application.

## Days Covered

### Day 1 — Sprint 4 Planning & Serialization

* Planned the deployment sprint.
* Saved the trained CNN model and deployment artifacts.
* Prepared reproducible requirements and model-serving files.

### Day 2 — Model Serving

* Learned how FastAPI can serve machine learning models through APIs.
* Covered prediction endpoints and input validation.

### Day 3 — Streamlit Dashboard

* Built an interactive Streamlit application.
* Added image upload and prediction output.
* Displayed the malignant probability for each prediction.

### Day 4 — Public Deployment

* Deployed the Streamlit application publicly.
* Tested the live application with multiple images.
* Verified the deployment environment and model files.

### Day 5 — Repository Polish & Project Review

* Updated the project README and documentation.
* Organized deployment files and project artifacts.
* Reviewed the project against the Definition of Done.
* Completed the Sprint 4 review and project retrospective.

## Project Results

At the selected classification threshold of **0.35**:

- Accuracy: **89.15%**
- Malignant Recall: **91.40%**
- Malignant F1-score: **89.39%**
- False Negatives: **86**

By the end of Week 9, the **Melanoma Skin Lesion Classification** project was completed as an end-to-end machine learning pipeline with a publicly deployed Streamlit application, ready for the Week 10 final presentation.
